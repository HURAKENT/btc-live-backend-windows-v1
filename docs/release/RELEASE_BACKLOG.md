# C9-C11 Non-Blocking Release Backlog

Every item below is deferred P2/P3 or nonessential work. None blocks 100% C9-C11
PREP progress or readiness to start the real 48-hour observation.

- Windows Service support, if a future operational requirement makes
  user-level Task Scheduler insufficient.
- Advanced backup retention, cataloging, and incremental-backup policies.
- Cloud backup.
- Telemetry and centralized log management.
- Extended chaos scenarios beyond the four bounded C10 failure classes.
- Extra Dashboard or other UI polish.
- Historical evidence hardening.
- PF1 work.
- Installer, updater, service-management platform, and other post-V1 work.
- C12/Linux migration and unrelated architecture refactoring.

Real-money orders, wallets, signing, authenticated CLOB writes, and any
weakening of `trading_approval=false` are prohibited scope, not backlog items.
